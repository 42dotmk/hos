hos

xbps repository for the hackable tools: hed, hterm, hwm, hws, htray, hnd, hmenu, hsm, hml, hstt, hweb, hbg, hai. The hos ISO ships them preinstalled and points here for updates; on plain Void Linux:

echo repository=https://42dotmk.github.io/hos | sudo tee /etc/xbps.d/10-hos-repository.conf
sudo xbps-install -S hed hterm hwm

The first sync asks to trust the repository key; its public half is hos-repo.pub in the hos repository. Packages are built by mkpkg from each tool's tree at release time, versioned from git.
